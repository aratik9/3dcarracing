
# 🏎️ 3D Car Racing Game

A simple car racing game built using HTML, CSS, and JavaScript.

## 🎮 Features

- Car racing gameplay
- 3D-style road and environment
- Left and right car controls
- Traffic cars and collision detection
- Speed indicator
- Score counter
- Mobile-friendly touch buttons
- Restart game option

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas API

## 🚀 How to Run

1. Download or clone this project.
2. Save the game code as `index.html`.
3. Open `index.html` in your web browser.
4. Click **START / RESTART** to play.

## 🎮 Controls

- ⬅️ Left button: Move the car left
- ➡️ Right button: Move the car right
- Avoid traffic cars to keep racing.

## 📱 Compatibility

Works in modern desktop and mobile web browsers.

## 📝 Note

This is a 2D Canvas-based game with simulated 3D perspective effects.
It does not use actual 3D models.
